# Electronics Sales Analysis Using Python

## 📌 Project Overview

This project analyzes electronics sales data using Python to understand sales patterns across different periods, locations, products, and order times.

The dataset contains over 185,000 sales records from 2019. The analysis focuses on preparing the data, calculating sales, and exploring patterns that can support better understanding of sales performance.

## 🛠️ Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🔍 Project Tasks

### Data Cleaning
- Checked the dataset for missing values
- Removed records with missing order information
- Removed repeated header rows within the dataset
- Converted numerical columns to the appropriate data types
- Converted order dates to datetime format

### Exploratory Data Analysis

The analysis explores:

- Monthly sales performance
- Sales by location
- Product sales patterns
- Order activity by time of day
- General sales trends and patterns

## 📊 Dataset

The dataset contains information such as:

- Order ID
- Product
- Quantity Ordered
- Price Each
- Order Date
- Purchase Address

A Sales column was also created by multiplying the quantity ordered by the price of each product.

## 📁 Project File

- `Electronics_Sales_Analysis_Using_Python.ipynb` — Jupyter Notebook containing the complete analysis.

## 🎯 Project Objective

The objective of this project is to demonstrate the use of Python for data cleaning, exploratory data analysis, and extracting useful insights from sales data.
